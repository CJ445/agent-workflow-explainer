    Overview · What you’ll build

    Six nodes. Four phases. One mental model.

    In n8n, an agent is a normal workflow. A trigger node starts the run, and the AI Agent node orchestrates it, with sub-nodes plugged into its slots: a chat model, memory, and tools. Here’s how each kind of node maps to that.

    1. Trigger node

      Chat Trigger

      Starts one execution per message. It outputs chatInput and sessionId.

    2. Root node

      AI Agent

      Builds the prompt, calls the model, runs any tool calls the model asks for, and loops until it can answer.

    3. Sub-nodes

      Model + Memory

      Gemini generates text and tool calls. Simple Memory supplies recent turns for the session.

    4. Tool sub-nodes

      Sheets + Gmail

      The model picks a tool by its name and description. n8n runs it with the stored OAuth credential.

    Key takeaways

    Names and descriptions are your API.
    The model chooses tools only by their node name and description. Make them specific and unambiguous.
    Memory is a window, not a mind.
    Simple Memory replays recent messages per session. A new session starts blank.
    Prompts guide. They don’t guarantee.
    The approval rule lives in the system message and tool description. For guaranteed sign-off, add a deterministic approval step.
